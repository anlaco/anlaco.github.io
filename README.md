# Ana — el playground

**<https://anlaco.github.io>** — el lenguaje Anlaco corriendo en tu navegador.

Esta es la **versión estable v0.26.0** publicada automáticamente con
`web/publicar.sh` desde el repositorio de desarrollo. Aquí no se desarrolla:
los cambios llegan solo cuando se cierra una versión nueva.

Anlaco es un lenguaje de programación que se lee como un libro, multilingüe
(español e inglés), pensado para que cualquiera pueda leer y revisar código.
